# Honey-Bot

A Django honeypot monitoring project with dashboard templates, event models, and database migrations.

## Explore the project

- [honeybot-project/requirements.txt](honeybot-project/requirements.txt)

## Source layout

| Directory | Contents |
| --- | --- |
| `honeybot-project/dashboard/` | Views, models, routes, and migrations |
| `honeybot-project/dashboard/templates/` | Dashboard and account pages |
| `honeybot-project/honeypot_monitor/` | Django project configuration |

Review the project configuration and dependency list before running the application. The repository also contains a database, a ZIP archive, and generated Python caches; these are not required to navigate the source code.
